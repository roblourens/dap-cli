<interfaces>
Actual user-facing mode contract to document:
```text
Default: JSON stdout envelope for automation.
Human flag: dap-cli --human <command> OR dap-cli <command> --human.
Environment default: DAP_CLI_HUMAN=1 enables human output when no explicit CLI mode is present.
Machine override: --no-human forces JSON even when DAP_CLI_HUMAN=1.
Payload JSON: command-level --json <json> remains request/config input for launch/attach/request/generated dap commands.
```
</interfaces>
