## Accomplishments

- Added `resolveOutputMode` with JSON default, explicit CLI precedence, and strict `DAP_CLI_HUMAN` parsing.

- Added `runCliHuman` for raw stdout tests without weakening the strict JSON `runCli` helper.

## Files Created/Modified

- `src/cli/outputMode.ts` - Resolves `json` vs `human` from explicit CLI state and `DAP_CLI_HUMAN`.

## Decisions Made

- `DAP_CLI_HUMAN` accepts only explicit true values (`1`, `true`, `yes`, `on`, `human`) and false values (`0`, `false`, `no`, `off`, `json`), after trimming and lowercasing.
- Invalid `DAP_CLI_HUMAN` values throw a handled usage error with code `invalid_output_mode_env`.
- Human output sanitizes external/debugger-provided text before terminal display but does not add color or TTY behavior in this plan.
