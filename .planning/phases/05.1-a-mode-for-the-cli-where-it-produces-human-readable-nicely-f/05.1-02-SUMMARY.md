## Files Created/Modified

- `src/cli/program.ts` - Creates the shared output writer, registers root mode flags, and passes OutputWriter to converted command groups.
- `src/cli/main.ts` - Renders handled failures through OutputWriter and returns `invalid_output_mode_env` when env parsing is the actual output failure.
- `src/cli/commands/controller.ts` - Uses OutputWriter for `start`, `status`, `stop`, and `stop-controller` success output.
- `src/cli/commands/sessions.ts` - Uses OutputWriter in the session command controller wrapper.
- `src/cli/commands/dapCore.ts` - Uses OutputWriter in launch/attach/request/capabilities/events final output.
- `tests/cli/jsonOutput.test.ts` - Covers root flags, env precedence, invalid env behavior, JSON defaults, and `launch --json` payload semantics.
- `tests/cli/sessionCommands.test.ts` - Covers human output for `sessions` against a live test controller.

## Decisions Made

- Exported `getProgramHumanOption` from `program.ts` so `main` and `createProgram` resolve mode from the same Commander state without unsafe casts.
- Converted controller commands in Task 1 so root human success behavior had a fast, deterministic command to test.
- Used `launch --json not-json` for the payload regression because launch validates its JSON config before contacting the controller.
