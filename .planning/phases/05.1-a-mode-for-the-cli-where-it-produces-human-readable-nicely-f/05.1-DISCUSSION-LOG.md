## Mode Selection

| Option | Description | Selected |
|--------|-------------|----------|
| JSON stays default | Human-readable mode is opt-in. Recommended because existing tests/docs and agent workflows parse JSON envelopes. | yes |
| Human by default in TTY | Interactive terminals get human output; non-TTY or pipes get JSON. | |
| Human becomes default | JSON requires an explicit flag everywhere. | |
| You decide | Let planning choose the safest default. | |

**User's choice:** JSON stays default
**Notes:** This preserves the current machine-readable default used by agents and tests.

| Option | Description | Selected |
|--------|-------------|----------|
| --format human\|json | Extensible global option; explicit JSON can be used in scripts too. | |
| --human | Short opt-in boolean, with JSON as the implicit fallback. | yes |
| --pretty | Friendly wording, but less precise about machine vs human output. | |
| You decide | Let the planner pick based on Commander integration. | |

**User's choice:** `--human`
**Notes:** This avoids colliding with existing command-level `--json` input-payload options.

| Option | Description | Selected |
|--------|-------------|----------|
| Only --human | No env/config defaults; safest for scripts and agent workflows. | |
| --human plus env var | For example DAP_CLI_OUTPUT=human, useful in shells but easier to surprise automation. | yes |
| --human plus config | Persist a preference under dap-cli config/state. | |
| You decide | Let planning choose. | |

**User's choice:** `--human` plus env var
**Notes:** The environment variable is intended as a human shell convenience, not as a new default for all users.

| Option | Description | Selected |
|--------|-------------|----------|
| Flag overrides env; JSON fallback | DAP_CLI_OUTPUT=human can be overridden by a future/explicit machine switch; invalid env falls back to JSON or handled usage per planner. | yes |
| Env is only used in TTY | DAP_CLI_OUTPUT=human affects interactive terminals, but pipes/non-TTY stay JSON. | |
| Env always wins unless --human absent | Simpler but can surprise scripts started from a configured shell. | |
| You decide | Let planning define precedence and validation. | |

**User's choice:** Flag overrides env; JSON fallback
**Notes:** Command-line output selection must take precedence over environment defaults.
