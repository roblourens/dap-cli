<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| workspace launch.json -> CLI resolver | Untrusted workspace file controls adapter launch arguments. |
| environment variables -> resolved config | Host env values can be copied into adapter config. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-05.2-01-01 | Tampering | `loadVSCodeLaunchJson` | mitigate | Keep the 256KB size bound and zod schema bounds before resolving nested values. |
| T-05.2-01-02 | Elevation of privilege | variable resolver | mitigate | Reject `${command:...}` and `${input:...}` before launch; do not execute VS Code commands or prompt. |
| T-05.2-01-03 | Information disclosure | `${env:NAME}` | accept | Environment substitution is user-requested launch.json behavior; only named variables are copied and failures are explicit. |
</threat_model>
