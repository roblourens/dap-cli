<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| resolved launch configs -> controller | Workspace launch.json can request multiple adapter processes. |
| controller runtime map -> session close | Close of one session may terminate multiple runtimes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-05.2-04-01 | Denial of service | compound startup | mitigate | Bound compound size via Plan 01 schema and start serially with cleanup on failure. |
| T-05.2-04-02 | Tampering | partial-start cleanup | mitigate | On failure, terminate runtimes and remove records before surfacing the structured error. |
| T-05.2-04-03 | Elevation of privilege | close cascade | mitigate | Cascade only within matching persisted compound id and only when `stopAll` is true. |
</threat_model>
