## Decisions Made

- Configuration/compound name collisions fail with `launch_config_ambiguous` rather than guessing which entry `--config` should select.
- `${command:...}` and `${input:...}` fail as unsupported launch variables because dap-cli cannot execute VS Code commands or prompt for launch inputs.
- `preLaunchTask`, `postDebugTask`, `presentation`, `internalConsoleOptions`, and `serverReadyAction` are stripped silently before adapter launch per the Phase 05.2 context decisions.
