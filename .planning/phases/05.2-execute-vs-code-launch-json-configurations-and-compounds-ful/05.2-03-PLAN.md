<interfaces>
Existing child sessions use `parent_session_id` and are not targetable. Compound members are different and must not reuse child-session semantics.

Current `SessionRecord` core shape:

```typescript
export interface SessionRecord {
  id: SessionId;
  name: string;
  adapter: string;
  lifecycle: SessionLifecycle;
  createdAt: string;
  updatedAt: string;
  ownedAdapter: OwnedAdapterMetadata;
  parent_session_id?: SessionId;
  paused?: boolean;
  stoppedReason?: string;
  stoppedThreadIds?: readonly number[];
}
```

Add optional compound metadata without changing the meaning of `parent_session_id`.
</interfaces>
</context>
