Use TypeScript with Node.js child_process (spawnSync) for shell commands, https/fetch for downloads, and fs for file checks. Make the script idempotent (safe to run multiple times). Log progress to stdout for user visibility.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network → setup script | Script downloads js-debug release asset from github.com over HTTPS |
| setup script → filesystem | Script writes adapter binaries to user's ~/.dap-cli/adapters/ directory |
| user Python environment → debugpy | Script installs debugpy Python package via pip into system or managed venv |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-supply-chain-01 | Tampering | scripts/setup-adapters.ts | mitigate | Pin js-debug version (v1.117.0) and verify download source is https://github.com/microsoft/vscode-js-debug/releases/. Hardcode expected tarball filename pattern. Use HTTPS for download (Node.js validates TLS by default). |
| T-04-supply-chain-02 | Tampering | scripts/setup-adapters.ts debugpy install | mitigate | Pin debugpy version (==1.8.20) in pip install command. Use system pip over HTTPS (PyPI validates TLS by default). Document expected package source: pypi.org/project/debugpy/. |
| T-04-path-traversal-03 | Tampering | scripts/setup-adapters.ts tar extraction | mitigate | Extract tarball into controlled directory (~/.dap-cli/adapters/js-debug/) without user input in path. Verify extracted files remain within target directory after extraction (check for `..` in tar member paths if using custom extraction, or rely on tar utility's default safe behavior). |
| T-04-privilege-04 | Elevation of Privilege | debugpy venv creation | accept | Script runs with user's normal permissions. Creates venv in user home directory (~/.dap-cli/venv/). No elevated privileges required or used. Risk accepted as normal package manager behavior. |
| T-04-debugpy-listener-05 | Information Disclosure | debugpy adapter listen port | mitigate | Debugpy adapter (when launched by dap-cli) defaults to stdio transport or local-only TCP listen. Built-in descriptor should not expose debug listener publicly. Verify debugpy descriptor uses `transport: 'stdio'` or localhost-bound socket only. |
</threat_model>
