<objective>
Close UAT gap 10 (blocker — `npm run test:smoke:chrome` fails because the test creates a fresh tmp `DAP_CLI_HOME` via `createCliTestEnv` but never provisions js-debug into it).

Purpose: The smoke test was added in plan 05-04 but was never actually exercised — only its env-gated `skipIf` ran in CI, so the failure was hidden. The other smoke test in the same file (`launches Chrome in headless mode`) only passes because it bypasses `runCli` and reaches into internal APIs that resolve adapters from the user's `~/.dap-cli/adapters`. Output: New helper in `src/testing/tempEnv.ts` that symlinks (or copies as fallback) the user's installed `~/.dap-cli/adapters/js-debug` into a tmp env. The `chrome-children-smoke` test calls it and passes when `DAP_CLI_RUN_BROWSER_SMOKES=1`.

  <action>
    1. Determine the source location for an installed adapter. Read `scripts/setup-adapters.ts` and `src/adapters/builtins/jsDebug.ts` to find the canonical install path. It is `<DAP_CLI_HOME or ~/.dap-cli>/adapters/<adapterId>`.
    2. Add an exported async function `provisionAdapterIntoTempEnv(target: TempDapCliEnv, adapterId: string, options?: { sourceDapCliHome?: string }): Promise<{ source: string; destination: string; mode: 'symlink' | 'copy' }>`.
       - Default `sourceDapCliHome` to the user's real DAP_CLI_HOME: `process.env.DAP_CLI_HOME ?? path.join(os.homedir(), '.dap-cli')`.
       - Source: `path.join(sourceDapCliHome, 'adapters', adapterId)`.
       - Destination: `path.join(target.dapCliHome, 'adapters', adapterId)`.
       - If source does not exist, throw `Error(\`Adapter "${adapterId}" is not installed at ${source}. Run \`npm run setup-adapters\` first.\`)`.
       - Ensure destination's parent directory exists (`fs.mkdir(..., { recursive: true })`).
       - Try `fs.symlink(source, destination, 'dir')` first; on failure (EPERM/EEXIST/ENOTSUP — Windows is not in scope for this CLI but be defensive), fall back to recursive copy via `fs.cp(source, destination, { recursive: true, dereference: true })`. Return which mode was used.
       - **Also copy any sibling JSON config the adapter relies on**: check whether `<sourceDapCliHome>/adapters.json` exists; if so, copy it to `<target.dapCliHome>/adapters.json` (overwrite). The js-debug AdapterRegistry reads adapters.json via `loadAdapterConfig`. Do not skip this — that's the same class of "silent missing setup" bug we're closing.
    3. Add a unit test inline (or in a new `tests/testing/tempEnv.test.ts` if cleaner) that:
       - Creates a fake source dap-cli-home with a stub `adapters/fake-adapter/installed.txt` file.
       - Calls `provisionAdapterIntoTempEnv` with that fake source.
       - Asserts the destination contains the file (whether via symlink or copy).
       - Asserts a clear error when the source does not exist.
