<objective>
Close UAT gaps 3 (test 5 — real js-debug interactive inspection reliability)
and 4 (test 6 — duplicate session name handling).

`src/sessions/activeSession.ts` already throws `session_ambiguous` when
`matches.length > 1`. The reported regression (`status --name node-demo`
returning `session_not_found` despite two `node-demo` records) is therefore
either a stale `dist/` build or a CLI command that bypasses
`resolveTargetSession`. This plan locks down the behavior with new tests
across every relevant command and exit-code path, fixes any bypasses
discovered, and adds a stale-session diagnostic for the
`adapter_transport_closed` failure mode the user hit on the running
duplicate.

Purpose: Make duplicate-name diagnosis ergonomic, and make stale js-debug
sessions self-diagnostic so users know to close + relaunch instead of
guessing.

Output: New CLI tests, an integration test for the stale-session flow, a
stale-session diagnostic renderer, and any small fixes to commands that
currently bypass `resolveTargetSession`.
</objective>
