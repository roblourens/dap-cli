<objective>
Close hand-driven gap H-1 from `05-UAT.md`: `dap-cli status` reports
`lifecycle: running` for sessions that are paused at entry or at a breakpoint.
A hand-driven user has no way to tell paused-vs-running from `status` alone.

Purpose: Restore the diagnostic value of `status` so the canonical hand-driven
smoke (Sequence A Steps 2 + 7) and Sequence B Step 5 can rely on `status` to
distinguish a paused program from a running one without having to dig through
`events`.

Output: `paused`, `stoppedReason`, `stoppedThreadIds` fields on
`SessionStatus`, kept in sync by the same controller event handler that
already maintains lifecycle.
</objective>
