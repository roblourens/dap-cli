  <action>
For each selected repo:
1. Clone shallowly into `tmp/phase-08-external-projects/<slug>`.
2. Record the commit SHA.
3. Inspect launch config and setup scripts before running anything.
4. Run only safe setup/build commands. Prefer install commands with lifecycle scripts disabled.
5. Use isolated `DAP_CLI_HOME="/Users/roblou/code/dap-cli/tmp/phase-08-external-projects/.dap-cli-home/<slug>"`.
6. Run `dap-cli launch --workspace <clone> --list-configs`.
7. Launch at least one viable config.
8. Set at least two breakpoints when suitable source files exist.
9. Poll `status` and `events`; inspect `threads`, `stack`, `scopes`, `variables`, and `evaluate` if the target reaches a stopped state.
10. Always close/cleanup/stop-controller for that `DAP_CLI_HOME`.

Treat external repos as untrusted. Do not run `sudo`, cloud login, deployment, Docker daemon operations, credentialed commands, destructive cleanup, or commands requiring secrets.
  </action>
