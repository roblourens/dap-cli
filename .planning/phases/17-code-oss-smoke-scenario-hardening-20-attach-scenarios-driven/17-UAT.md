## Ergonomic Papercuts

- `sessions --json` and `status --json` are repeatedly attempted by agents; JSON mode is global `--no-human`, while command-level `--json` means request payload.
- `cleanup --purge` returns `controller_unavailable` if the controller is not running, which makes pre-cleanup steps brittle.
- Attach timeouts often hide the simpler root cause that the configured port is not listening.
- Parent `loaded-sources` can be empty while child sessions exist but are not targetable, making breakpoint/source diagnosis noisy.
- `pause` can return `ok:true` with `pause_no_stopped_event`, requiring follow-up status/stack checks for classification.
