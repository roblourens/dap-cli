<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internal errors -> agent JSON | Internal failures become machine-readable output. |
| adapter diagnostics -> JSON payload | External stderr/log metadata may contain sensitive data. |
| test subprocesses -> local machine | Integration tests spawn and stop controller/fake-adapter processes. |
| event cache -> agent workflow | Agents poll cached events and must not depend on streaming commands. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-08-01 | Information Disclosure | structured errors | mitigate | Tests assert bounded stderr tails/log paths and no raw stacks, full env, or full logs in JSON. |
| T-01-08-02 | Tampering | stdout contract | mitigate | Tests enforce exactly one JSON object on stdout for representative commands. |
| T-01-08-03 | Denial of Service | integration subprocesses | mitigate | `runCli` uses isolated `DAP_CLI_HOME`, stops controllers, and removes only test-owned directories. |
| T-01-08-04 | Spoofing | event semantics | mitigate | Boundary tests block wait/watch/stream/subscribe commands from entering Phase 1. |
</threat_model>
