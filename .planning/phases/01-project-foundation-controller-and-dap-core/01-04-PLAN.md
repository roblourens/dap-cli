<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| controller -> session store | Session summaries and active target state are persisted locally. |
| CLI session selector -> controller session manager | User-supplied session IDs select controller-owned state. |
| cleanup -> OS processes | Cleanup can signal adapter processes only with ownership proof. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04-01 | Tampering | session store | mitigate | Validate persisted summaries and recover with structured errors for corrupt state. |
| T-01-04-02 | Information Disclosure | persisted session state | mitigate | Persist summaries only; do not persist raw launch env or full adapter stderr. |
| T-01-04-03 | Elevation of Privilege | cleanup process signaling | mitigate | Only signal pids where `ownedAdapter.startedByDapCli === true`. |
| T-01-04-04 | Spoofing | session target selection | mitigate | Require exact session ID match and structured errors for missing or unavailable sessions. |
</threat_model>
