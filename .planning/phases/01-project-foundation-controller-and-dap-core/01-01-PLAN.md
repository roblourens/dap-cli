<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell argv -> CLI parser | Untrusted agent/user input enters command parsing. |
| CLI source -> internal modules | CLI code must not bypass controller/session/protocol boundaries. |
| package scripts -> local machine | Developer scripts execute local tooling and must be predictable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01-01 | Tampering | build/test scripts | mitigate | Keep script names explicit and make `check` run typecheck, lint, test, and build. |
| T-01-01-02 | Elevation of Privilege | CLI imports | mitigate | Boundary test blocks CLI imports from protocol and adapter process modules. |
| T-01-01-03 | Repudiation | process exit behavior | mitigate | Centralize exit code values in `src/cli/exitCodes.ts` for later JSON/error mapping. |
</threat_model>
