Create these message contracts.

```typescript
export interface DapRequestMessage<TArguments = unknown> {
  seq: number;
  type: 'request';
  command: string;
  arguments?: TArguments;
}
export interface DapResponseMessage<TBody = unknown> {
  seq: number;
  type: 'response';
  request_seq: number;
  success: boolean;
  command: string;
  message?: string;
  body?: TBody;
}
export interface DapEventMessage<TBody = unknown> {
  seq: number;
  type: 'event';
  event: string;
  body?: TBody;
}
```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-05-01 | Tampering | DAP frame parser | mitigate | Validate header separator, content length, JSON shape, and message discriminants. |
| T-01-05-02 | Denial of Service | event cache | mitigate | Use fixed capacity and dropped counts instead of unbounded event storage. |
| T-01-05-03 | Information Disclosure | event payload summaries | mitigate | Store bounded recent events and leave full diagnostics to log paths introduced by adapter layers. |
