<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| controller -> adapter process | dap-cli starts external adapter-like processes through descriptors. |
| adapter stderr -> diagnostics | External process stderr becomes bounded diagnostic data. |
| fake adapter -> protocol lifecycle | Test adapter messages drive controller/session state. |
| CLI dap commands -> controller DAP routes | Agent-supplied DAP command/args cross into an active session. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-07-01 | Elevation of Privilege | process adapter spawn | mitigate | Use `spawn` with args array and `shell: false`; validate descriptor shapes. |
| T-01-07-02 | Information Disclosure | adapter stderr/logs | mitigate | Bound stderr tails and expose log paths structurally instead of dumping full logs to stdout. |
| T-01-07-03 | Spoofing | socket descriptor | mitigate | Restrict Phase 1 socket descriptors to `127.0.0.1`. |
| T-01-07-04 | Tampering | internal dap.request payload | mitigate | Validate route payloads with zod and route only to an explicit or active controller-owned session. |
</threat_model>
