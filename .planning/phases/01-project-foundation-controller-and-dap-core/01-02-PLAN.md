<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI parser -> stdout JSON | Handled command outcomes become machine-readable output consumed by agents. |
| error objects -> JSON payload | Internal failures may contain sensitive stack or environment details. |
| environment -> path helper | `DAP_CLI_HOME` controls where dap-cli writes state/log files. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02-01 | Tampering | stdout JSON contract | mitigate | Centralize JSON writes in `src/cli/output.ts` and test exactly one stdout object for handled outcomes. |
| T-01-02-02 | Information Disclosure | error mapping | mitigate | Internal unexpected errors omit raw stack traces and full env/log contents from JSON. |
| T-01-02-03 | Spoofing | `DAP_CLI_HOME` | mitigate | Resolve `DAP_CLI_HOME` to an absolute path and keep tests isolated by setting it explicitly. |
| T-01-02-04 | Repudiation | JSON metadata | mitigate | Every envelope includes command and timestamp metadata. |
</threat_model>
