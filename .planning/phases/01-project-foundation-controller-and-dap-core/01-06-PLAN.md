<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| protocol client -> adapter transport | dap-cli writes DAP requests to external adapters. |
| adapter responses/events -> DAP client | External messages resolve requests or update lifecycle state. |
| lifecycle state -> session status | DAP lifecycle becomes agent-visible polling state in later plans. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06-01 | Tampering | DAP response matching | mitigate | Match responses by `request_seq` and reject unknown/duplicate response seq values safely. |
| T-01-06-02 | Denial of Service | pending requests | mitigate | Apply request timeouts and reject all pending requests on transport close. |
| T-01-06-03 | Repudiation | request diagnostics | mitigate | Track `lastRequest` with command, seq, and timestamp for later diagnostics. |
| T-01-06-04 | Spoofing | socket transport host | mitigate | Socket connect helper only accepts `127.0.0.1` host in Phase 1 scope. |
</threat_model>
