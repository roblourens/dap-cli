<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI process -> controller IPC | Local clients send JSON requests to the controller. |
| discovery file -> controller client | Clients trust endpoint and pid data from local state. |
| controller server -> filesystem | Discovery and logs are written under dap-cli home. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-03-01 | Spoofing | controller discovery | mitigate | Validate discovery with zod, require version `1`, check pid and endpoint health before trusting it. |
| T-01-03-02 | Denial of Service | controller IPC | mitigate | Add per-request timeout, reject malformed JSON, and close sockets after responses. |
| T-01-03-03 | Tampering | discovery file | mitigate | Store discovery under `DAP_CLI_HOME`-resolved state root and remove stale discovery on failed health checks. |
| T-01-03-04 | Repudiation | controller diagnostics | mitigate | Include command/method, controller pid when known, and timestamp in JSON meta or diagnostics. |
</threat_model>
