<objective>
Finalize the failure-surface contract. Audit every error path in `src/adapters/provision/`, make sure each emits a `provision_*` code with diagnostics that name the recovery flag/env var/install step, snapshot-test each envelope so regressions are caught, and add architectural assertions that lock in D-10 (provision lives in `src/`), D-11 (no shell-out tar/unzip in `src/` OR `scripts/`), D-15 (provision_-namespaced errors), and D-21 (checksums are real 64-char hex, not placeholders).

Purpose: The user-facing value of this whole phase is "when something goes wrong, you get a clear, copy-pasteable next step". Without snapshot coverage, those diagnostics can silently rot. Without architectural guards, a future contributor can re-introduce `spawnSync('tar', ...)` and the project regresses to today's brittle behavior.

Output: Diagnostic-message audit across all six provision modules, one new test file with ~13 envelope snapshots, and four new assertions in the existing architecture test.
</objective>
