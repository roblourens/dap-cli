7. **Concurrency (D-08/D-19).** Multiple dap-cli processes are safe: per-adapter lockfile, 90s wait timeout, 5min stale threshold. If a process is killed mid-install, the next process recovers (atomic rename means no half-installed state).
8. **Network / proxy.** Honors `HTTPS_PROXY`, `HTTP_PROXY`, `NO_PROXY`. Falls back to direct fetch when unset. Set `GITHUB_TOKEN` to raise GitHub release rate limits.
9. **Error codes reference (D-15).** Table mirroring the 21-04 catalogue:

   | Code | When | Fix |
   |------|------|-----|
   | `provision_consent_required` | Non-TTY without `--yes` | Re-run with `--yes` or set `DAP_CLI_ASSUME_YES=1`. |
   | `provision_consent_declined` | You answered no | Re-run and answer `y`, or pass `--yes`. |
   | `provision_network_error` | HTTP failure | Check connectivity; see proxy section. |
   | `provision_proxy_error` | Proxy fetch failed | Verify `HTTPS_PROXY`; bypass with `NO_PROXY=github.com`. |
   | `provision_rate_limited` | GitHub 403 + rate limit | Set `GITHUB_TOKEN`. |
   | `provision_checksum_mismatch` | Downloaded SHA mismatch | Re-run; if persistent, [file an issue](https://github.com/roblourens/dap-cli/issues). |
   | `provision_python3_missing` | `python3` not on PATH | Install Python 3.8+ (`brew install python` / `apt install python3`). |
   | `provision_python3_venv_unavailable` | venv module missing | `apt install python3-venv`. |
   | `provision_pip_install_failed` | pip non-zero | Inspect stderr in diagnostics; pin alternate index via `--index-url`. |
   | `provision_arch_unsupported` | Platform/arch not supported | See supported set above. |
   | `provision_cache_unwritable` | EACCES/EROFS/ENOSPC | Override `DAP_CLI_ADAPTERS_DIR`. |
   | `provision_lock_timeout` | Another process held the lock 90s | Delete the sentinel path printed in diagnostics. |
   | `provision_extract_failed` | Archive corrupt or unsafe | Re-run; if persistent, file an issue. |

10. **Troubleshooting.** "I want to re-prompt." → `rm ~/.dap-cli/adapters/<id>/.consent-<version>`. "I want to reinstall." → `rm -rf ~/.dap-cli/adapters/<id>/`. "I want to disable provisioning entirely." → Pre-install adapters into `DAP_CLI_ADAPTERS_DIR` (the consent marker + present binary means no prompt, no download).
11. **Security notes.** SHA-256 verified for js-debug + delve; debugpy delegated to pip; archives extracted via in-process tar/yauzl (no `tar`/`unzip` subprocess); zip-slip and symlink rejection enforced.
