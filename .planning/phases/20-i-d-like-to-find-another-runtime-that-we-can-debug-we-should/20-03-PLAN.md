Real-adapter matrix to implement:
- launch debug: Go package/app under Delve `mode: "debug"`;
- test debug: package test under Delve `mode: "test"`;
- exec debug: prebuilt symbol-friendly binary under Delve `mode: "exec"`, built with `go build -gcflags=all="-N -l"`;
- local attach: long-lived Go process with DAP attach `{ mode: "local", processId }`, gated by `DAP_CLI_RUN_DELVE_ATTACH_SMOKE=1` if environment sensitivity remains.

Every paused workflow must assert a stopped event plus meaningful threads/stack/scopes/variables/evaluate evidence before continue/disconnect cleanup.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test runner → real `dlv dap` process | Integration tests execute a debugger binary and accept DAP data over localhost. |
| attach test → live local process PID | The debugger controls a process the test intentionally launches. |
| fixture build → generated debug binary | Go build output is later executed in exec-mode debug tests. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-03-01 | Tampering | exec-mode fixture binary | mitigate | Build only repo-owned fixtures with explicit `go build -gcflags=all="-N -l"`; do not execute downloaded binaries in the automated suite. |
| T-20-03-02 | Denial of Service | orphaned Delve or Go processes | mitigate | Every test uses `finally` cleanup through existing transport/child handles; attach cleanup targets only the child PID it created. |
| T-20-03-03 | Elevation | local PID attach | mitigate | Gate attach via `DAP_CLI_RUN_DELVE_ATTACH_SMOKE=1`, attach only to the test-owned fixture PID, and assert lifecycle behavior. |
| T-20-03-04 | Information Disclosure | adapter/test logs containing source paths or locals | mitigate | Keep logs in test temp paths and assert behavior from deterministic fixture data, not user/project secrets. |
</threat_model>
