## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-02-01 | Tampering | `launchConfigTypeMap` and Delve mapping | mitigate | Add narrow `go -> delve` mapping only; keep existing config validation and regression tests for malformed configs. |
| T-20-02-02 | Information Disclosure | raw launch/attach configs | accept | Config fields already flow to adapters in this CLI; this plan preserves existing behavior and does not add new logging of program args or process metadata. |
| T-20-02-03 | Denial of Service | ambiguous adapter/type inference | mitigate | Table-driven tests assert explicit adapter/type precedence still wins over `.go` inference, preventing surprise re-routing. |
| T-20-02-04 | Elevation / Spoofing | attach PID field | mitigate | Treat `processId` as Delve-native data only; do not translate arbitrary ports or shell snippets into process selection. Real attach lifecycle is verified in Plan 20-03. |
