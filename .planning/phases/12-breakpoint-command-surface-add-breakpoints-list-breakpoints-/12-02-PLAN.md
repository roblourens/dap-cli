<objective>
Replace the analysis.md §3 misleading "verification timed out / check source maps / check outFiles" generic with a structured, in-band diagnostic that names the actual failure mode (wrong process, no source-map match, line mismatch). When `breakpoints set` returns any unverified breakpoint, dap-cli automatically follows up with `loadedSources`, classifies the failure, and attaches a `verificationDiagnostic` object to the success payload — including the literal recipe an agent should run next.

Purpose: Today an external agent who attached to the wrong helper process gets identical "check source maps" diagnostics for every cause (wrong process, missing source map, off-by-one line). All three look the same in stdout, so triage requires manual `dap loaded-sources` plumbing the agent has to remember. This plan turns the implicit "now run loaded-sources" step into an automatic side effect of the request that surfaced the symptom — and surfaces the recipe inline so the next-step is always one grep away.
Output: A small augmentation in `breakpoints set` that runs ONE follow-up DAP roundtrip on unverified responses, attaches a structured diagnostic, and never blocks the user's primary success.
</objective>

       ```typescript
       async function buildVerificationDiagnostic(
         client: ControllerClient,
         requestedPath: string,
         breakpoints: ReadonlyArray<{ verified?: boolean; ... }>,
         name: string | undefined,
       ): Promise<VerificationDiagnostic> {
         const totalCount = breakpoints.length;
         const unverifiedCount = breakpoints.filter(b => b.verified === false).length;
         // Recipe is the literal command an agent should run next; static string by design.
         const recipe = `dap-cli dap loaded-sources${name === undefined ? '' : ` --name ${name}`}`;
         // 1. Probe capabilities; if loadedSources not supported, short-circuit.
         try {
           const caps = await client.request('dap.capabilities', name === undefined ? undefined : { name }) as { capabilities?: { supportsLoadedSourcesRequest?: boolean } };
           if (caps?.capabilities?.supportsLoadedSourcesRequest !== true) {
             return { unverifiedCount, totalCount, loadedSourcesCount: -1, matchingLoadedSources: [], hint: `${unverifiedCount} of ${totalCount} breakpoints unverified; loadedSources lookup failed (adapter does not support loadedSources). Try running: ${recipe}`, recipe };
           }
         } catch (err) {
           return { unverifiedCount, totalCount, loadedSourcesCount: -1, matchingLoadedSources: [], hint: `${unverifiedCount} of ${totalCount} breakpoints unverified; loadedSources lookup failed (capabilities probe failed: ${describeError(err)}). Try running: ${recipe}`, recipe };
         }
         // 2. Fetch loadedSources.
         let loaded;
         try {
           loaded = await client.request('dap.request', { command: 'loadedSources', args: {}, name }) as { sources?: ReadonlyArray<{ path?: string; name?: string }> };
         } catch (err) {
           return { unverifiedCount, totalCount, loadedSourcesCount: -1, matchingLoadedSources: [], hint: `${unverifiedCount} of ${totalCount} breakpoints unverified; loadedSources lookup failed (${describeError(err)}). Try running: ${recipe}`, recipe };
         }
         const sources = loaded.sources ?? [];
         const loadedSourcesCount = sources.length;
         // 3. Match: exact-path OR basename. Case-insensitive on win32, case-sensitive elsewhere.
         const wantBasename = path.basename(requestedPath);
         const cmp: (a: string, b: string) => boolean = process.platform === 'win32'
           ? (a, b) => a.toLowerCase() === b.toLowerCase()
           : (a, b) => a === b;
         const matchingLoadedSources = sources.filter(s => typeof s.path === 'string' && (cmp(s.path, requestedPath) || cmp(path.basename(s.path), wantBasename))).map(s => ({ path: s.path as string, ...(typeof s.name === 'string' ? { name: s.name } : {}) }));
         // 4. Pick the hint based on the matrix.
         let hint: string;
         if (loadedSourcesCount === 0) {
           hint = `${unverifiedCount} of ${totalCount} breakpoints unverified; debuggee has loaded 0 sources — likely attached to the wrong process. Run: ${recipe}`;
         } else if (matchingLoadedSources.length === 0) {
           hint = `${unverifiedCount} of ${totalCount} breakpoints unverified; ${loadedSourcesCount} sources loaded but none match ${wantBasename}. Check source maps / outFiles. Run: ${recipe}`;
         } else {
           hint = `${unverifiedCount} of ${totalCount} breakpoints unverified despite ${matchingLoadedSources.length} matching loaded source(s). Check breakpoint line numbers. Run: ${recipe}`;
         }
         return { unverifiedCount, totalCount, loadedSourcesCount, matchingLoadedSources, hint, recipe };
       }
       ```
