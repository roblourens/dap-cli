<objective>
Define the honest Rust configuration contract: map `type: "lldb"` to CodeLLDB for explicit compiled executables without `cargo`, and reject every raw Cargo-bearing configuration while preserving the no-`.rs` inference boundary.

Purpose: CodeLLDB's VS Code extension resolves `cargo` before native DAP; forwarding it unmodified would create a misleading support promise and late native failures.
Output: Launch/config routing changes and regression tests for mapping, limitation diagnostics, and inference boundaries.
</objective>
