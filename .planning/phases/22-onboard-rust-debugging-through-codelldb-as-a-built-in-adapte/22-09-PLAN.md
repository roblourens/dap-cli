<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Public Rust source/Cargo metadata to execution environment | Cargo builds can execute build scripts and proc macros from untrusted repositories. |
| Subagent report to accepted evidence | A delegated summary can omit unsafe commands, wrong turns, or cleanup failures. |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-09-01 | Tampering / Elevation | public Cargo/build.rs/proc macros | mitigate | Pre-execution ledger screens all executable surfaces; use selected exact commands only after owned passes. |
| T-22-09-02 | Information Disclosure | host environment during external run | mitigate | Prefer non-root contained run without host home/socket/secrets and disable debug-time network; otherwise record isolated bounded host fallback. |
| T-22-09-03 | Repudiation | subagent result claims | mitigate | Result records require SHA, commands, isolation, evidence and cleanup; Plan 22-10 audits JSONL before accepting passes. |
| T-22-09-04 | Elevation | external attach | mitigate | Do not attach to non-owned/public service processes; attempts use launched scenario-owned targets only unless explicitly screened ownership is recorded. |
| T-22-09-SC | Tampering | CodeLLDB runtime in external validation | mitigate | Use the approved checksum-verified isolated adapter cache from prior product/owned proof. |
</threat_model>
