## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Compiled Rust fixture to native debugger | A native debugger executes and observes a process, even when source is owned. |
| PID attach request to host process table | A wrong PID or policy workaround could inspect or affect unintended processes. |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-07-01 | Tampering | fixture build/run | mitigate | Fixture has no dependencies, build script, or proc macros; build/run is repo-owned and isolated. |
| T-22-07-02 | Elevation / Information Disclosure | attach flow | mitigate | Attach only scenario-owned PID using native `pid`; never alter host security policy; accept documented blocker. |
| T-22-07-03 | Denial of Service | native process lifecycle | mitigate | Integration and evidence require explicit adapter/debuggee teardown and cleanup verification. |
| T-22-07-SC | Tampering | adapter payload | mitigate | Uses only cache validated and launched under passing R-00/R-01 evidence. |
</threat_model>
