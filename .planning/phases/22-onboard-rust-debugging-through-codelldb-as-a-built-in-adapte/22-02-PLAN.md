## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Release URL to local cache | Native VSIX content crosses the network and is persisted for execution. |
| ZIP archive to filesystem | Nested native/runtime paths can attempt traversal or incomplete installation. |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-02-01 | Tampering | `CODELLDB_CHECKSUMS` and downloaded VSIX | mitigate | Encode only R-00-approved digests; verify SHA before `extractZip`; checksum mismatch tests leave no canonical install. |
| T-22-02-02 | Tampering / DoS | VSIX extraction and runtime completeness | mitigate | Reuse safe ZIP extraction and atomic full-tree install; synthetic tests require all R-00 runtime entries. |
| T-22-02-03 | Repudiation | unconsented native download | mitigate | Reuse consent markers and non-TTY typed failure; tests prove no download on refusal. |
| T-22-02-04 | Tampering / DoS | concurrent cache publication | mitigate | Extend the existing concurrency suite with cold/warm CodeLLDB callers proving one cold download and atomic full-tree install, zero warm downloads, and no partial canonical cache. |
| T-22-02-SC | Tampering | external payload provenance | mitigate | Implementation is blocked until Plan 22-01's VSIX provenance/caching pass; no new ecosystem packages are installed. |
