## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Bounded prompt to fresh subagent commands | A subagent may take unsafe or confusing steps outside intended workflow. |
| JSONL transcript to pass claim | Accepted results must be grounded in actual commands and cleanup, not prose. |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-10-01 | Tampering / Elevation | delegated public Cargo actions | mitigate | Prompts point only at screened SHAs/commands and isolated execution; transcript audit records deviations as blockers. |
| T-22-10-02 | Repudiation | agent success summaries | mitigate | Require identified JSONL, actual command/cleanup audit and append-only initial/rerun record before accepting pass. |
| T-22-10-03 | Information Disclosure | transcript reporting | mitigate | Record necessary command/evidence facts locally; do not publish or copy credentials/secrets from logs. |
| T-22-10-SC | Tampering | runtime/cache used by agents | mitigate | Prompts require isolated cache using gate-approved provision path and forbid fallback to unapproved binaries. |
</threat_model>
