<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| js-debug binary → dap-cli process | js-debug runs as subprocess with access to target app files and memory |
| Fixture code → test environment | Test fixtures execute arbitrary JS/TS code during smoke tests |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering | js-debug binary path | mitigate | Resolve js-debug path from trusted locations only (dapCliHome, node_modules) - do not allow arbitrary paths from env vars without validation |
| T-03-07 | Information Disclosure | js-debug logs | accept | js-debug may log sensitive app data during debugging - this is intended behavior. Users control log paths via adapter config. |
| T-03-08 | Denial of Service | Chrome port conflicts | mitigate | Use dynamic port allocation for Chrome remote debugging in smoke tests - avoid hardcoded port 9222 |
| T-03-09 | Elevation of Privilege | Node.js execution | accept | Launching Node.js apps is the core feature - users explicitly provide programs to debug. Document that dap-cli executes target programs with user privileges. |
</threat_model>
