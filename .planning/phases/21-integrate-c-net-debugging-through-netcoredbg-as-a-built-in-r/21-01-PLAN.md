<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| GitHub release archive → local adapter cache | Untrusted downloaded bytes become executable code |
| Archive extraction → filesystem | Archive contents may attempt path traversal |
| CLI launch → adapter process | dap-cli starts a local executable selected from PATH/cache |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-21-01 | Tampering | `scripts/setup-adapters.ts` | mitigate | Verify NetCoreDbg archive sha256 before extraction using the release digest table for `3.1.3-1062`. |
| T-21-02 | Elevation | archive extraction | mitigate | Extract only into `DAP_CLI_HOME/adapters/netcoredbg/`; reject missing expected executable; prevent path traversal by validating extracted paths stay under target dir. |
| T-21-03 | Spoofing | adapter resolution | mitigate | Prefer usable PATH `netcoredbg`; otherwise use exact provisioned executable path; readiness must run `--version` or `--help`. |
| T-21-04 | Tampering | Microsoft `vsdbg` | mitigate | Do not download, bundle, mention as bundled, or redistribute `vsdbg`. |
| T-21-05 | DoS | unsupported `darwin/arm64` | mitigate | Emit typed `netcoredbg_unsupported_platform` unless a proven Rosetta/user-provided fallback is implemented. |
</threat_model>
