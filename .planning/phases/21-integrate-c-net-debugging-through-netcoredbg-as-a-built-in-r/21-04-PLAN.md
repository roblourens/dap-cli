## Trust Boundaries

| Boundary | Description |
|---|---|
| Docs → user terminal | Examples may be copied into real workspaces |
| Agent skill → public repo debugging | Guidance can cause agents to execute untrusted projects |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-21-15 | Elevation | docs examples | mitigate | State build-first DLL launch; do not instruct running `.csproj` auto-build or launch tasks. |
| T-21-16 | Elevation | attach docs | mitigate | Attach only to same-machine owned PIDs; show `disconnect` with `terminateDebuggee:false`; cleanup exact owned process. |
| T-21-17 | Tampering | adapter setup docs | mitigate | Mention digest-verified pinned NetCoreDbg assets and no `vsdbg` bundling. |
| T-21-18 | DoS | macOS arm64 | mitigate | Document unsupported/proven fallback behavior from Plan 21-01. |
</threat_model>
