<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Public GitHub repo → local checkout | Untrusted source/manifests enter workspace |
| `dotnet restore` → network/package cache | Dependency fetch may run untrusted package/build logic |
| External debug execution → local processes | Debuggee can run arbitrary code from public repo |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-21-19 | Elevation | public repo commands | mitigate | Screen README, `.sln`, `.csproj`, `.props`, `.targets`, `Directory.Build.*`, task files, devcontainer files, setup docs, package feed config, scripts, Makefiles, launch configs, and all script/build hook locations before execution. |
| T-21-20 | Tampering | dependency restore | mitigate | Separate `dotnet restore` from build/debug; isolate `DOTNET_CLI_HOME` and `NUGET_PACKAGES`. |
| T-21-21 | Information Disclosure | environment | mitigate | Use isolated `DAP_CLI_HOME`, `DOTNET_CLI_HOME`, `NUGET_PACKAGES`; no credentials; no host home. |
| T-21-22 | DoS | process cleanup | mitigate | Record exact commands and cleanup; terminate only phase-owned sessions/processes. |
| T-21-23 | Repudiation | validation claims | mitigate | Preserve repo URL, commit SHA, commands, result, evidence, cleanup. |
</threat_model>
