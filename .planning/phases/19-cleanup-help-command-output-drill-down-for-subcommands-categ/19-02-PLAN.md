<objective>
Group the top-level command list in `dap-cli help` into the seven locked
categories from D-03 / HELP-03 using commander v14's per-command
`helpGroup()` API. No new commands, no renamed commands, no behavioral
changes — purely a help-rendering reorganization so the long flat list
becomes scannable.

Purpose: Today `dap-cli help` dumps ~25 commands as one flat `Commands:`
block, which is hard to scan and obscures which commands belong to which
phase of a debug workflow (lifecycle vs. inspection vs. execution control
vs. escape hatches).

Output: Categorized help output where each top-level command appears under
its assigned heading, plus a regression test that pins the category
membership.
</objective>
