<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI options -> DAP arguments | User-provided flags/JSON become adapter request arguments. |
| Alias metadata -> controller route | Handwritten aliases select generated commands and send requests. |
| Paused-state references -> adapter | frameId, variablesReference, and sourceReference values are adapter-scoped and stateful. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Tampering | src/cli/commands/dapGenerated.ts | mitigate | Parse generated `--json` with the existing usageError pattern and route all requests through `dap.request` validation. |
| T-02-03-02 | Elevation of Privilege | src/cli/commands/dapAliases.ts | mitigate | Require aliases to use getDapGeneratedCommand and sendGeneratedDapRequest; do not add direct adapter/protocol imports to CLI aliases. |
| T-02-03-03 | Repudiation | execution-control aliases | mitigate | Preserve JSON envelope metadata command names and controller diagnostics so sent DAP command, session, and adapter context remain visible on failure. |
| T-02-03-04 | Denial of Service | paused-state inspection aliases | mitigate | Validate numeric IDs and JSON inputs before controller IPC; malformed values produce handled usage errors instead of adapter crashes. |
</threat_model>
